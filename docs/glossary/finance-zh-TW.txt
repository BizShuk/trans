# 台股法說會術語表 (en → zh-TW)
#
# 用法：複製到 ~/.config/translate/glossary.txt，或以 --glossary 指定本檔。
# 格式：每行「原文<TAB>替換」，# 開頭為註解，長詞優先套用。
#
# 這份表`不是`通用中文修正，而是`特定領域`的說法。它安全的前提是：
# 你處理的文本確實是財報與法說會。`總利潤` 在別的語境本來就是總利潤，
# 把它一律換成毛利率，在非財經文本上就是製造錯誤。
#
# 每一條的左欄都是`實測`到的模型輸出（opus-mt-en-zh 與 nllb-600m，2026-08-06），
# 不是憑空想像的錯法。模型換版之後要重新量一次。
